# Autonomous-AI-Data-Analyst-Agent
Autonomous AI data analyst agent: upload a messy CSV and it cleans the data, plans its own statistical analyses (Plan-Act-Reflect), ranks insights with confidence scores, checks every numeric claim against computed results, and exports PDF/Word reports.
